🔄 OpenMAIC 数据迁移工具

将课堂数据从 localhost 迁移到 IP 地址

⚠️ 重要说明：
由于浏览器安全策略，localhost:3000 和 192.168.1.4:3000 的 IndexedDB 是相互独立的。此工具可以帮助你导出数据并导入到新的域名。

📤 步骤 1: 导出数据（在 localhost 页面执行）

1. 打开新标签页访问：http://localhost:3000/

2. 按 F12 打开开发者工具 → Console

3. 复制以下代码并执行：

// 导出所有课堂数据 async function exportData() { const db = await new Promise((resolve, reject) => { const request = indexedDB.open('MAIC-Database'); request.onsuccess = () => resolve(request.result); request.onerror = () => reject(request.error); }); const transaction = db.transaction(['stages', 'scenes'], 'readonly'); const stagesStore = transaction.objectStore('stages'); const scenesStore = transaction.objectStore('scenes'); const [stages, scenes] = await Promise.all([ new Promise(resolve => { const req = stagesStore.getAll(); req.onsuccess = () => resolve(req.result); }), new Promise(resolve => { const req = scenesStore.getAll(); req.onsuccess = () => resolve(req.result); }) ]); const data = { stages, scenes }; const json = JSON.stringify(data); const blob = new Blob([json], { type: 'application/json' }); const url = URL.createObjectURL(blob); const a = document.createElement('a'); a.href = url; a.download = 'openmaic-backup.json'; a.click(); console.log('✅ 导出成功！共', stages.length, '个课堂，', scenes.length, '个场景'); console.log('📦 文件已下载：openmaic-backup.json'); } exportData();

📥 步骤 2: 导入数据（在此页面执行）

1. 确保你刚才下载的 openmaic-backup.json 文件可用

2. 点击下方按钮选择文件


✅ 步骤 3: 验证数据

导入完成后：

  • 刷新此页面
  • 访问 http://192.168.1.4:3000/mobile
  • 应该能看到所有课堂了！
